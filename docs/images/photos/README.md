# Настоящие фото проверки

Здесь подготовлены семь мест для реальных кадров. Пока изображения отсутствуют, основной README выводит подпись «Ожидается реальный прогон». Синтетические снимки интерфейса лежат на уровень выше и не смешиваются с этой галереей.

## Как добавить

1. Провести соответствующий шаг из `docs/RELEASE_CHECKLIST.md` на Windows 11 Pro с камерой.
2. Получить согласие добровольного тестового участника на публикацию конкретного кадра. Использовать тестовое имя; не снимать чужие лица, пароль, токен, ссылку пакета и посторонние окна.
3. Сохранить разрешённое изображение с именем из `manifest.json`. Пример: `docs/images/photos/camera-error.png`. Не заменять PNG-файл изображением другого формата с переименованным расширением; если нужен JPG, изменить соответствующее имя в манифесте.
4. Уточнить подпись `caption`: дата, версия EXE, камера/Windows, действие и фактический результат. Не писать «работает», если сценарий не завершился успешно. Для ошибки описать также восстановление.
5. Из корня проекта выполнить `.venv/Scripts/python.exe scripts/update_readme_gallery.py`. Проверить README и каждое фото перед коммитом. Скрипт обновляет только блок между `REAL_PHOTOS_START` и `REAL_PHOTOS_END`.

Для проверки актуальности без записи: `python scripts/update_readme_gallery.py --check`.

## Что снимать

| Имя | Содержание |
| --- | --- |
| `student-start.png` | Подключённый агент и тот же ПК в кабинете |
| `camera-calibration.png` | Реальный предпросмотр и этап калибровки |
| `phone-lock.png` | Телефон, событие и логическая приостановка |
| `gaze-lock.png` | Третий эпизод одного направления, счётчик 3/3 |
| `camera-error.png` | Читаемая техническая ошибка камеры/записи |
| `teacher-review.png` | Настоящий клип и решение с причиной |
| `windows-protection.png` | Принятая защита ОС вместе с отдельным протоколом обходов |

Не генерировать «настоящие фото» и не рисовать успешное состояние поверх снимка. Снимок окна LOCKED подтверждает только отображение статуса. Для проверки Windows нужны выполненные попытки Alt+Tab, Win, Task Manager, завершения процесса и аварийного выхода по протоколу безопасности.

Исходные записи с людьми держать в закрытом каталоге вне Git. Папка этой галереи и основной README входят в исходный ZIP выпуска; добавлять сюда только материалы, разрешённые для распространения.
