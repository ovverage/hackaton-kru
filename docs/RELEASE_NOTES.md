# Qorgau 0.3.1 — Windows Installer · Hackathon prerelease

## Скачать и установить

**Нужен готовый клиент? Скачайте `Qorgau-Student-Setup-0.3.1-x64.exe` из Assets ниже.** Это установщик, а не архив исходников: запустите его, пройдите мастер и откройте Qorgau Student из меню «Пуск». Python и модели устанавливать отдельно не нужно.

Установка для текущего пользователя, русский/английский мастер, ярлык в меню «Пуск» и необязательный ярлык на рабочем столе. Удаление — через список приложений Windows. Профиль `.qorgau`, записи и настройки сохраняются. Перед обновлением или удалением завершите экзамен и закройте клиент; установщик не завершает работающий агент принудительно.

В CI проверены установка в путь с пробелами, ярлыки и регистрация удаления, повторная установка, запрет изменений при работающем клиенте, самопроверка установленного приложения, удаление и сохранение данных. Отчёт — `installer-selftest.json`.

Установщик пока **не имеет цифровой подписи**. Проверяйте источник и SHA-256; не отключайте антивирус или SmartScreen. Это не сертифицированный защищённый экзаменационный клиент.

Альтернатива: `Qorgau-Student-Windows-x64.zip` — portable-папка; распакуйте её целиком вместе с `_internal`. `Source code` — только исходники.

Обучение не менялось в 0.3.1: [модели и отчёты экспериментов из 0.3.0](https://github.com/ovverage/hackaton-kru/releases/download/v0.3.0/Qorgau-Training-Experiments.zip).

## Возможности клиента

Windows-клиент теперь поддерживает выбор главного окна или приложения, ограничение горячих клавиш и других окон, полноэкранное сообщение «Позовите преподавателя» с моментами срабатываний и разблокировку паролем преподавателя.

Веб-тесты запускаются в отдельном Qorgau Browser: один разрешённый origin, без вкладок, popup и скачиваний. Камера настраивается по восьми позициям. Полная portable-сборка включает CV-библиотеки, официальные модели и H.264-кодировщик.

Усилены проверки команд, защищён переход LOCKED→OPEN на сервере, добавлены сохраняемая история причин, ограничение перебора пароля, остановка при потере сети/окна/удалённой сессии и контроль изменения экранов. Подробный разбор обходов — `docs/SECURITY.md`.

Выполнены эксперименты обучения на собственных данных команды и открытом наборе. Веса и реальные метрики доступны в пакете экспериментов по ссылке выше; исходные фото/видео не публикуются. Экспериментальный gaze-классификатор недостаточно переносим между участниками и не используется для автоматических решений.

Артефакты: установщик Windows x64 .exe, portable ZIP, SHA256SUMS, отчёты проверки установщика и упакованного приложения, веб-сборка.

Статус: хакатонный prerelease, не сертифицированный lockdown-клиент. Обычный пользовательский процесс не блокирует администратора ОС или Ctrl+Alt+Delete. Для реального экзамена нужна управляемая Windows-конфигурация и интерактивная приёмка на целевых ПК. CI проверяет API, правила, GUI, Windows API и инференс внутри сборки; это не испытание живой камерой в аудитории.
