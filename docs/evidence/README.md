# Обезличенные свидетельства выпуска

Результаты от 6 октября 2026 года. Это выполненные автоматические проверки Qorgau 0.3.0, не физическая приёмка камеры или Windows.

| Файл | Содержание и границы |
| --- | --- |
| `python-tests.json` | Итог pytest: число тестов, длительность и предупреждение |
| `public-release.json` | HTTPS, WSS, скачанный EXE, регистрация и отзыв; идентификаторы тестовых устройств удалены |
| `exe-selftest.json` | Проверка моделей и H.264 в собранном EXE на синтетических кадрах |
| `load-50-2h.json` | Полный двухчасовой HTTP-прогон 50 клиентов; без видеонагрузки и камер |
| `mixed-load.json` | 50 клиентов, события, синтетические клипы, повторы команд и WSS; около двух минут на локальном сервере |

Числа перенесены из фактических отчётов `.local/evidence/`. В отчёте нагрузки удалены только PID процессов; значения CPU и памяти сохранены. Пароли, токены, профили и реальные видеозаписи сюда не копируются. Перечень исходных частных отчётов и подробные условия испытаний — в [VERIFICATION.md](../VERIFICATION.md).

Поля `PASS` означают успешность конкретного сценария с указанными условиями. Они не подтверждают все требования ТЗ, точность распознавания на людях, защиту Windows или поддержку 50 физических камер.
