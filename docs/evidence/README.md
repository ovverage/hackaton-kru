Числа перенесены из фактических отчётов `.local/evidence/`. В отчёте нагрузки удалены только PID процессов; значения CPU и памяти сохранены. Пароли, токены, профили и реальные видеозаписи сюда не копируются. Перечень исходных частных отчётов и подробные условия испытаний — в [VERIFICATION.md](../VERIFICATION.md).

Поля `PASS` означают успешность конкретного сценария с указанными условиями. Они не подтверждают все требования ТЗ, точность распознавания на людях, защиту Windows или поддержку 50 физических камер.
