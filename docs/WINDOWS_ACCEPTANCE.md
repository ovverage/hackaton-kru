# Приёмка Windows перед показом жюри

CI проверяет настоящий Win32 API, установку/снятие hooks на тестовом окне и собранный .exe. Ниже — отдельные интерактивные проверки, которые нужно выполнить на демонстрационном ПК с камерой. Не отмечать их выполненными на основании Linux-тестов или CI.

| Проверка | Ожидаемый результат | Результат на целевом ПК |
|---|---|---|
| Установщик .exe | Мастер установки, ярлык в «Пуск», запуск без Python; без повышения прав | Не проверено |
| Обновление / удаление | Требуется закрыть клиент; профиль `.qorgau` сохраняется | Не проверено |
| Распаковка, первый запуск, регистрация | Окно открывается без установленного Python; ПК появляется в кабинете | Не проверено |
| Главное окно | В списке доступны реальные окна, выбор отражается в кабинете | Не проверено |
| Приложение .exe | Запускается выбранная программа, фиксируется её главное окно | Не проверено |
| Камера | Восемь позиций завершаются; ошибочная калибровка не принимается | Не проверено |
| Сайт | Qorgau Browser открывает тест; login/submit внутри origin работают | Не проверено |
| Клавиши | Alt+Tab, Win, PrtScn, Ctrl+C/V, Ctrl+Tab и Ctrl+L перехвачены | Не проверено |
| Мышь | Другое окно/панель задач/соседний экран недоступны; ответы в тесте доступны | Не проверено |
| Телефон | При уверенном обнаружении экран «Позовите преподавателя»; справа причина и момент | Не проверено |
| Взгляд | Три эпизода вниз ≥5 с блокируют; другие направления считаются отдельно | Не проверено |
| Пароль | Ошибочный не снимает блокировку; правильный после устранения причины начинает новый цикл | Не проверено |
| Запись | Реальный MP4 появляется в панели и открывается около срабатывания | Не проверено |
| Сеть | Через 10 с без сервера GUARDED блокируется, после возврата нужна команда | Не проверено |
| Камера отключена | Техническая блокировка; возвращение камеры само не разблокирует | Не проверено |
| Закрытие теста / дополнительный монитор | Техническое событие и блокировка | Не проверено |
| Перезапуск агента | Активный сеанс восстанавливается заблокированным; завершить из кабинета и подготовить новый | Не проверено |
| Завершение | Hooks сняты, обычные клавиши работают, другие окна доступны, ответы не отправлены автоматически | Не проверено |

Зафиксировать Windows edition/build, CPU/RAM, модель камеры, версию Qorgau, адрес теста, дату и исполнителя. При неисправной защите окна не использовать OBSERVE как незаметную замену GUARDED: явно перейти на помеченный демонстрационный стенд.
