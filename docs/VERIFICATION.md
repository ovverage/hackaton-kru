# Выбранное окно, материалы и продолжение — 0.4.4

6 октября 2026 года. Локально: 155 тестов прошли, проверка реального захвата ввода пропущена на рабочем столе пользователя. Дополнительная проверка полноэкранного Edge запускается только на изолированном Windows runner. Ruff и сборка TypeScript/Vite прошли.

В локальном браузере проверены две вкладки активного сеанса, список заблокированных ПК, видео только выбранного ПК и фактическое применение UNLOCK: компьютер исчез из заблокированных, состояние OPEN, цикл 2. Стенд содержит два синтетических агента и тестовую видеотаблицу; это не проверка физической камеры.

Qt offscreen: компактное окно ученика и экран блокировки с фотографией и рамкой телефона. Регрессионные проверки покрывают скрытие полноэкранных поверхностей после разрешения, возврат фокуса, ограничение ввода при потерянном окне, REVIEW + UNLOCK в одной синхронизации и запрет снятия новой блокировки старой командой.

Результат сборки и публикации фиксируется отдельно после прохождения CI. Физическая камера, реальные условия аудитории и системный kiosk требуют аппаратной приёмки.
