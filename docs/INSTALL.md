# Установка и первый экзамен Qorgau 0.5.2

Нужен Windows x64, веб-камера и свободное место для локальных материалов. Python, Qt, CV-модели и H.264-кодировщик входят в полную сборку. GPU и обучающие датасеты на компьютере студента не требуются. Linux/macOS/ARM64-клиент в этом выпуске не поставляется.

## Скачать и проверить

Выберите [онлайн-приложение](https://212.19.134.23/api/student/download) или [автономное приложение](https://212.19.134.23/api/student/download-offline). Установщик, portable-пакет и контрольные суммы находятся в [GitHub Releases](https://github.com/ovverage/hackaton-kru/releases). Документ описывает 0.5.2; перед показом проверьте версию скачанного файла и соответствующий опубликованный выпуск. Обновление сайта не заменяет уже установленный EXE.

```powershell
Get-FileHash .\Qorgau-Student.exe -Algorithm SHA256
Get-FileHash .\Qorgau-Offline.exe -Algorithm SHA256
```

Сравните результат с `SHA256SUMS.txt` того же выпуска. Установщик пока не имеет подписи коммерческого издателя; хеш подтверждает целостность относительно релиза, а не заменяет подпись. Не отключайте антивирус или системные политики ради запуска.

Самостоятельный EXE переносится одним файлом. Если выбран ZIP варианта onedir, распакуйте **всю** папку с `_internal`. Не запускайте установленную и переносимую копии одновременно с одним профилем.

Установщик работает в профиле пользователя, обычно `%LOCALAPPDATA%\Programs\Qorgau Student`, без службы и без изменения системных политик. Закройте приложение через трей, завершив экзамен, перед установкой или обновлением. Языки интерфейса приложения: русский, казахский и английский; язык ввода Windows переключается отдельно.

## Онлайн-экзамен

1. Преподаватель открывает [кабинет](https://212.19.134.23/). Демонстрационный доступ 0.5.2: **`admin` / `admin`**. Для работы с реальными участниками смените этот общедоступный пароль.
2. Студент запускает `Qorgau-Student.exe`. Обычный публичный клиент уже содержит адрес сервера, сам регистрирует ПК и сохраняет личный отзывной токен. Код кабинета вводить не нужно. Статус подключения должен подтверждаться свежим обменом с сервером.
3. Преподаватель создаёт сеанс, выбирает ПК и сайт для Qorgau Browser либо отдельную программу. В последнем случае на ПК выбирают фактическое открытое окно программы.
4. Команда начала открывает подготовку камеры и девять точек на выбранном мониторе. На каждую точку отведено три секунды; плохие измерения повторяются автоматически. Приготовление идёт до контроля экзамена, без штрафов за сами движения к точкам.
5. После успешной настройки приложение проверяет камеру и защиту, открывает выбранную среду и начинает контроль. Известную программу удалённого управления нужно закрыть, если проверка её обнаружила.
6. При блокировке преподаватель разбирает причину и разрешает продолжение либо завершает сеанс. Ctrl+Alt+Q и кнопка преподавателя открывают доступ у ПК. Завершение Qorgau не отправляет ответы на сайте теста.

Для исключения известного преподавателя из второго лица добавьте его профиль в кабинете и отдельно разрешите этому точному устройству получать шаблоны. Публичная регистрация сама такого доступа не даёт. Проверка лица при разблокировке требует связи с сервером; предусмотрен пароль преподавателя.

## Автономный экзамен

1. Запустите `Qorgau-Offline.exe` либо `Qorgau-Student.exe --offline`.
2. В новом локальном профиле резервный демонстрационный пароль — **`admin`**. Преподаватель меняет его до настоящего экзамена. Ранее установленный пароль не перезаписывается; на диск сохраняется Argon2-хеш.
3. Выберите окно программы или конкретную вкладку Chrome/Edge. Для вкладки сначала установите и свяжите расширение, как описано ниже. Обычный выбор окна браузера не идентифицирует вкладку.
4. Нажмите начало, выберите камеру/монитор и пройдите точки. Плохая точка повторяется; Esc отменяет подготовку. Неготовая калибровка не превращается в разрешение стартовать.
5. Разблокировка или завершение доступны преподавателю. Локальный пароль работает без сети. Проверка лица через онлайн-базу требует соединения; сам сайт теста также может требовать интернет.
6. После завершения захват и запись останавливаются, материалы этого локального экзамена очищаются. Настройки и пароль остаются. Автономные события и клипы не загружаются в кабинет.

## Привязать вкладку Chrome/Edge

Установите распакованное расширение из комплектного `extension/`, откройте его настройку и скопируйте ID расширения и UUID браузерного профиля. Для того же профиля агента выполните:

```powershell
Qorgau-Student.exe --data "ПОЛНЫЙ_КАТАЛОГ_ПРОФИЛЯ" --install-extension ID_РАСШИРЕНИЯ --browser-instance UUID_ПРОФИЛЯ --browser edge
```

Для Chrome используйте `--browser chrome`. Регистрация Native Messaging относится к текущему пользователю Windows. Затем выберите именно нужную вкладку в приложении. Смена профиля или закрытие вкладки требуют новой проверки; расширение не заменяет защиту Windows. Подробности — [SECURITY.md](SECURITY.md).

## Совместимость теста и восстановление

Qorgau не требует Moodle/Platonus: он контролирует выбранную среду. Его встроенный браузер разрешает один origin, запрещает дополнительные окна, скачивание и выбор файлов. Внешний SSO и переходы между доменами необходимо проверить до экзамена. Произвольная программа также не становится совместимой только по наличию окна.

Смена раскладки разрешена через Win+Пробел и кнопку «Язык ввода» в Qorgau Browser. Остальные ограничения клавиш продолжают действовать. Во время активного сеанса не меняйте монитор, масштаб и положение камеры. Изменение монитора или отказ камеры отключают готовность; пройдите восстановление камеры и калибровки, затем получите разрешение преподавателя.

## Профиль, обновление и удаление

Профиль по умолчанию хранится в `%USERPROFILE%\.qorgau`; для отдельного теста разработчика используйте `--data`. Удаление установленного приложения сохраняет профиль с настройками, токеном и очередью материалов. Не удаляйте его во время экзамена. Завершение автономного сеанса очищает только принадлежащие ему материалы; это не удаление всего профиля.

При переустановке сохраняется регистрация. Другое имя пользователя Windows — другой профиль. Автозапуск и системные службы установщик не включает. Для организованной аудитории способ развёртывания и аварийного доступа согласуют с её администратором.

Сборка установщика описана в [README](../README.md#сборка-и-проверка); исходник — `packaging/windows/qorgau.iss`. Тесты установки/repair/удаления из `scripts/test_installer.py` запускаются на одноразовом CI-runner, не на рабочем экзаменационном ПК. [Аппаратная приёмка](RELEASE_CHECKLIST.md) обязательна отдельно от самопроверки EXE.
