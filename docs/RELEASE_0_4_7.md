## Что изменилось

| Сценарий | Поведение 0.4.7 |
| --- | --- |
| Подготовка камеры | Живой предпросмотр остаётся на компьютере ученика. После проверки изображения и взгляда на монитор ученик нажимает «Использовать эту камеру»; отмена освобождает камеру. |
| Отведение взгляда | Во время активного контроля появляется «Верните взгляд на монитор». Баннер не забирает фокус и не перехватывает нажатия. Напоминание само не добавляет балл: прежние временные правила сохранены. |
| Общая картина сеанса | Кабинет показывает число компьютеров на связи, выполняющих тест, заблокированных и событий без решения. Значения берутся из текущего snapshot. |
| Состояние отдельного ПК | Камера, взгляд и защита показаны отдельно. Потеря связи делает данные неактуальными; поддержка защиты не выдаётся за подтверждённую работу hooks. В карточке доступна фактическая версия моделей агента. |
| Проверка события во время теста | Очередь «Требуют внимания» открывает запись и решение без завершения сеанса. Недоступное видео и истёкший срок хранения обозначаются явно. |
| Сайт тестирования | По умолчанию новый сеанс использует Qorgau Browser и указанный преподавателем адрес. У браузера одна web-view, нет вкладок; новые окна, загрузки и навигация на другой origin блокируются. |
| Отдельное приложение | Сохранён режим выбранного окна программы. Обычный браузер с `guardable=false` нельзя подставить вместо защищённого окна: проверка есть в интерфейсе, сервере и агенте. |
| Доступность панели | Диалоги удерживают клавиатурный фокус; Escape закрывает верхний диалог. Форма сеанса и сводка проверены на узком экране, учитывается reduced motion. |

Перед первым запуском теста на реальном сайте проверьте его в Qorgau Browser:
авторизация или переход на другой origin будут заблокированы. Обновление сайта
не заменяет уже скачанный EXE — на ПК ученика должна быть версия **0.4.7**.

## Новое обучение ведётся отдельно

Для переобучения подготовлены скачанные **WIDER FACE**, **COCO 2017**,
**MPIIFaceGaze** и **Gaze360**. На момент подготовки этой записи реальное обучение
детектора лиц на WIDER FACE сохраняет checkpoints после первых эпох;
подготовка COCO выполняется параллельно, объединённый gaze-пайплайн ждёт
проверенной распаковки данных на сервере. Это промежуточный статус, а не завершённая
оценка моделей. [Снимок запуска с временем и параметрами](../training/reports/public-training-launch-2026-10-07.json).

В публичном приложении остаются прежние YOLO11n телефона, YOLOv8n лиц, MediaPipe
и gaze-классификатор из [model-manifest.json](../model-manifest.json).
Метрики прежнего набора описаны в [карточке моделей](MODEL_CARD_2026_10_06.md);
они не переносятся на новые эксперименты. Новые веса можно рассматривать для
выпуска после независимого test, проверки CPU ONNX и временных сценариев на
видео, с учётом лицензий исходных датасетов.

## Границы соответствия ТЗ

- Телефон в кадре и его подъём/удержание не доказывают направление объектива
  или факт фотографирования монитора. `PHONE_AIM_REVIEW` — повод проверить
  запись; классификатор доказанного намерения съёмки в этом выпуске отсутствует.
- Оценка взгляда — направление относительно исходной позы, а не измеренная
  точка на экране. Автоматический сигнал требует контекста и решения преподавателя.
- Отсутствие видимого лица не равно отсутствию человека. Новый обучаемый
  детектор `person` из COCO не объявлен частью моделей 0.4.7.
- WinAPI hooks ограничивают пользовательский сеанс Windows. Они не перекрывают
  Ctrl+Alt+Del, secure desktop и действия администратора; строгий системный kiosk
  не заявляется.
