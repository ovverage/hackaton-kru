# Соответствие кейсу № 3

Источник требований: «Кейс №3 КРУ и Qostanai Hub рус (2).pdf», страница 2,
предоставлен пользователем 7 октября 2026 года. Это карта реализации и проверки,
а не утверждение об измеренной точности переобученных моделей.

## Изменения панели 7 октября

- Сводка сеанса показывает только реальные значения из snapshot: компьютеры на
  связи, выполняющие тест, заблокированные и события без решения.
- При отсутствии связи индикаторы контроля становятся неактуальными, даже если
  в последнем heartbeat камера и защита были включены. Наличие поддержки hooks
  само по себе не выдаётся за активную защиту во время теста.
- Очередь последних событий доступна во время активного сеанса. Из неё можно
  открыть запись, указать причину и передать решение через существующий API.
- Форма нового сеанса явно разделяет сайт в Qorgau Browser и выбранное окно
  приложения. Для встроенного браузера не требуется заранее выбирать внешнее
  окно на компьютере ученика.
- Диалоги сохраняют клавиатурный фокус внутри верхнего открытого окна;
  `Escape` закрывает только верхний диалог. Учтён reduced motion.

## Проверки интерфейса

`web/tests/sessionStatus.test.mjs` проверяет готовность обеих сред, запрет
обычного браузера в режиме выбранного окна, неактуальные capabilities при
разрыве связи, состояние защиты, ошибку камеры и очередь событий. Вместе с
`commands.test.mjs` — 13 проверок. TypeScript и production-сборка Vite проходят.

Визуальная проверка на изолированных данных выполнена для активного сеанса,
просмотра события и формы нового сеанса, включая ширину 390 px. Изолированные
данные не попадают в production и не представляют результаты обучения или
реальных студентов. Ошибок JavaScript в этих сценариях не обнаружено.

## Приёмка моделей и выпуска

Перед продвижением новых весов необходимы зафиксированные train/dev/test,
оценка без подбора порогов на финальном test, отдельные метрики каждой задачи,
проверка ONNX относительно checkpoint, задержка CPU и проверка временных правил
на локальном видео. Версии, SHA256 и результаты должны соответствовать фактически
включённым в сборку файлам. Права на распространение моделей необходимо сверять
с сохранёнными лицензиями каждого датасета; эта карта соответствия не даёт прав
публиковать исследовательские веса.
