# Подготовка открытых данных для следующего обучения Qorgau

Этот этап скачивает, распаковывает и проверяет исходные данные. Модели, pretrained-веса и обучение не запускаются. Данные по умолчанию находятся в `data/datasets/` и исключены из Git.

```text
data/datasets/
  DATASETS.json
  mpiifacegaze/{archives,raw,sources}/
  gaze360/{archives,raw,sources}/
  widerface/{archives,raw,sources}/
  coco2017/{archives,raw,sources}/
```

В каждой папке `status.json` содержит этап, происхождение, результаты проверок и ошибки. Общий `DATASETS.json` объединяет эти записи с фактическим размером файлов и состоянием незавершённых загрузок. `ready` выставляется только после проверок конкретного набора. Промежуточный реестр — снимок на указанное время, а не гарантия, что процесс продолжает работать.

Во время работы общий реестр обновляет этапы и состояние архивов без повторного обхода всех фотографий; поля общего занятого места остаются `null`. Полный подсчёт выполняется в конце и по команде `--report-only`, чтобы обход сотен тысяч файлов не мешал распаковке на HDD.

## Повторный запуск и докачка

Python 3.11+; окружение для подготовки данных можно установить отдельно от библиотек обучения:

```powershell
python -m pip install -e '.[datasets]'
python -m training.datasets.prepare --root data/datasets
```

Для полного запуска рекомендуется 150 ГБ свободного места; перед каждым скачиванием и распаковкой проверяется необходимый объём. Архивы сохраняются вместе с распакованными данными. Не запускайте два процесса для одного набора одновременно. Команда повторяет проверки и докачивает прерванные файлы; `.source.json` привязывает частичную загрузку к конкретному URL, размеру и ожидаемым контрольным суммам.

```powershell
# Только выбранные наборы, до двух параллельных процессов.
python -m training.datasets.prepare --only gaze360 coco2017 --workers 2

# При медленных длинных HTTP-потоках: по 2 запроса диапазонов на набор.
python -m training.datasets.prepare --only gaze360 coco2017 --workers 2 --range-workers 2

# Пересоздать общий реестр из имеющихся файлов, без сети и загрузок.
python -m training.datasets.prepare --report-only

# Один набор; остальные не затрагиваются.
python -m training.datasets.mpiifacegaze --root data/datasets
```

Загрузчик использует HTTP/1.1, повторные попытки и Range с проверкой `Content-Range`. Если сервер игнорирует Range и отдаёт HTTP 200, файл записывается заново. Байты разных источников не смешиваются. Для Hugging Face сохраняются метаданные LFS и точный commit; каждый архив сверяется с опубликованным SHA-256. Для официального MPIIFaceGaze вычисляется SHA-256 и проверяется ZIP CRC; сторонняя авторская копия имеет отдельное имя и опубликованный MD5, неприменимый к официальному ZIP.

ZIP распаковывается с проверкой CRC, размера и безопасного пути каждого файла. При повторном запуске существующие файлы сверяются с CRC. Шесть частей Gaze360 читаются как единый TAR в порядке aa–af, без создания второй копии большого архива. Проверяются TAR-заголовки и полные хеши частей; сохраняются `metadata.mat` и все JPEG головы, включая `unused`. JPEG головы также декодируются для проверки. Тело не извлекается.

Режим `--range-workers` загружает диапазоны по 64 МиБ, проверяет точный HTTP 206, границы, общий размер и длину каждого блока. Уже скачанный непрерывный `.part` сохраняется, блоки собираются строго по смещению; полный SHA-256 проверяется перед переименованием в готовый архив. Временный кэш `.ranges/` требует дополнительного места и очищается от собственных блоков после успешной проверки. Блокировки ОС защищают файлы и наборы от одновременных конкурирующих запусков.

## Проверяемое содержимое

| Набор | Проверка |
|---|---|
| MPIIFaceGaze | p00–p14, исходные `pxx.txt`, все ссылки на изображения, числовые поля, Calibration: Camera.mat, monitorPose.mat, screenSize.mat |
| Gaze360 | Все шесть частей и суммарный размер 30 548 756 480 байт; head-кадры, metadata.mat, официальные train/validation/test и соответствие векторов взгляда |
| WIDER FACE | 12 880 / 3 226 / 16 097 фотографий, ссылки в исходной bbox-разметке train/val; у test публичных bbox нет |
| COCO 2017 | 118 287 / 5 000 изображений; полная разметка, соответствие файлов и image_id, class `person` определяется по `categories` |

COCO сохраняется целиком, в том числе изображения без людей. Индекс `category_id` исходного COCO не равен индексу класса YOLO. Взгляд в сторону или вниз сам по себе не доказывает использование телефона или шпаргалки; длительность позже вычисляется по последовательности предсказаний и таймеру. Gaze360 не задаёт границы монитора.

## Источники и ограничения

Оригинальные страницы, лицензии и JSON-метаданные сохранены в `sources/` каждого набора; URL и SHA-256 загрузок — в реестре. Gaze360 получен из закреплённого зеркала сообщества, не подтверждённого авторами. Ограничения исследовательского использования, производных моделей и распространения у наборов различаются; сведения сохранены без предположения, что лицензия кода автоматически покрывает изображения. ETH-XGaze и EYEDIAP не скачиваются.

Для переноса на GPU-сервер нужно сохранить дерево данных, `sources/`, `status.json` и `DATASETS.json`; сведения об абсолютных локальных путях в исходном реестре останутся историческими. Запуск `--report-only` на сервере обновит верхние пути и размеры; пути внутри исходных квитанций сохраняют происхождение файлов. Обучение — отдельный следующий этап.

## Проверки загрузчика

```powershell
python -m pip install -e '.[datasets,test]'
python -m pytest tests/test_dataset_acquisition.py tests/test_dataset_ranges.py tests/test_detection_datasets.py training/datasets/test_mpiifacegaze.py tests/test_dataset_gaze360.py -q
```

Тесты проверяют докачку и неправильные диапазоны, несовпадение хешей, запрет смешивания источников, безопасную распаковку и проверки разметки. Они не скачивают реальные наборы целиком.
