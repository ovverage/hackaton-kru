# Qorgau — новый дизайн

Макеты приложения ученика (.exe) и кабинета преподавателя, готовые к передаче в разработку.

## Что внутри

| Папка или файл | Что это |
| --- | --- |
| `html/index.html` | Оглавление: все 18 экранов. Откройте в браузере, интернет не нужен. |
| `html/*.html`, `html/qorgau.css` | Макеты экранов и общая таблица стилей с токенами. Страницы кабинета адаптивные. |
| `png/exe`, `png/web`, `png/web-phone` | Снимки экранов: окна ученика, кабинет на 1440 px и на телефоне 390 px. |
| `DESIGN.md` | Спецификация: идея, токены, компоненты, словарь, какой экран в каком файле кода, откуда брать данные. |
| `tokens.json` | Цвета, шрифт, размеры в машиночитаемом виде. |
| `fonts/` | Geologica (лицензия OFL): `static/*.ttf` для Qt, `Geologica-Variable.woff` для сайта, `Geologica-Variable.ttf` исходник. |
| `CODEX_PROMPT.md` | Промпт для Codex, чтобы перенести дизайн в код. |
| `source-canvas/` | Исходники холста Design (`*.dc.html`, `canvas.json`), если понадобится загрузить их обратно. |

## Как передать в Codex

1. Распакуйте архив в репозиторий: `design/redesign-2026-10/`. Должны получиться `design/redesign-2026-10/DESIGN.md`, `design/redesign-2026-10/html/` и так далее.
2. Откройте Codex в корне репозитория и вставьте текст из `CODEX_PROMPT.md`.
