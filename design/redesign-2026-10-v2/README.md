# Qorgau — дизайн, версия 2 (navy)

Макеты приложения ученика (.exe) и кабинета преподавателя в исходной гамме бренда. Реализованные экраны находятся в `implemented/`. Версия 1 заменена; её макеты сохранены в [истории Git v0.5.1](https://github.com/ovverage/hackaton-kru/tree/v0.5.1/design/redesign-2026-10).

## Что внутри

| Папка или файл | Что это |
| --- | --- |
| `html/index.html` | Оглавление всех 18 экранов. Открывается в браузере без интернета. |
| `html/*.html`, `html/qorgau.css` | Макеты экранов и общая таблица стилей с токенами. Страницы кабинета адаптивные: сузьте окно до телефона. |
| `png/exe`, `png/web`, `png/web-phone` | Снимки: окна ученика (2×), кабинет на 1440 px и на 390 px. |
| `DESIGN.md` | Спецификация: что изменилось с v1, токены, компоненты, словарь, экран → файл кода, экраны без макета, откуда брать данные. |
| `tokens.json` | Цвета с контрастом, шрифт, размеры, логотип. |
| `fonts/` | Geologica (OFL). В репозитории уже лежит в `agent/fonts/` и `web/src/assets/fonts/`; здесь для справки. |
| `CODEX_PROMPT.md` | Промпт для Codex. |
| `source-canvas/` | Исходники холста Design (`*.dc.html`, `canvas.json`, `qorgau.css`). |

## Как передать в Codex

1. Распакуйте архив в репозиторий так, чтобы получилось `design/redesign-2026-10-v2/DESIGN.md`, `design/redesign-2026-10-v2/html/` и так далее.
2. Откройте Codex в корне репозитория на актуальном `main` и вставьте текст из `CODEX_PROMPT.md`.
3. Codex работает в ветке `redesign/navy-v2`, коммитит по фазам и ничего не пушит. В конце пришлёт отчёт и скриншоты в `design/redesign-2026-10-v2/implemented/`.
