## Обоснованные отличия от макетов

1. Время начала теста берётся из `exam.created_at`: отдельного точного времени старта участника нет. Время паузы — из последнего события соответствующей причины; при отсутствии достоверного времени оно скрыто.
2. В API нет времени завершения экзамена, поэтому длительность и диапазон начала/окончания завершённых сеансов не выдумываются. Шкала завершённого сеанса не выдаёт последнюю запись за момент завершения.
3. Версия правил конкретного сеанса уже есть в `exam.rule_version` и показана там, где относится к этому сеансу. Глобальная актуальная версия не передаётся — общие правила и новый сеанс без номера.
4. Продление видео на 7 дней запрещено действующим сервером. Кнопки продления нет; срок берётся из существующего `media.expires_at`, показано действующее хранение 2 часа.
5. Неготовые компьютеры нельзя обещать автоматически добавить позднее: сохранены реальные проверки `preparationIssue` и доступный выбор. Современный интерактивный агент может завершать настройку после команды старта — эта возможность сохранена.
6. Рамки распознавания уже наносятся агентом на реальные кадры/видео. UI не рисует дополнительные выдуманные координаты или проценты. Продолжительность записи берётся из границ фрагмента, отдельно от длительности самого события.
7. В подготовке нет лишнего захвата камеры ради миниатюры; увеличенная высота диагностики и прокрутка маленького окна сохранены. Длинные проверяемые сообщения публичной модели взгляда и поворота головы сохранены.
8. Порог счётчика взгляда 5 с в `shared/rules.py` задан литералом, а не экспортируемой константой. Для визуального кольца используется тот же порог без изменения правил. После засчитанной отметки UI не обещает новую отметку через 0 с.
9. У приложения нет достоверного общего числа закрытых/ещё не открытых Qorgau и глобальной «последней версии агента». Такие значения и признак устаревания не выдумываются.
10. Qt offscreen предоставляет виртуальный экран 800×800 для калибровки. WebEngine не отдаёт корректный общий снимок браузера на этом хосте: сохранён отдельный `grab()` настоящей кнопки. Проверка этого снимка не заменяет проверку Windows-браузера; штатная Windows-сборка дополнительно выполняет native recovery и packaged self-tests.

## Область публикации

Прямой запрос пользователя включает push и deploy и имеет приоритет над запретом push во вложенном задании. Публикация выполняется существующим GitHub Actions workflow после завершения параллельной публикации предыдущих исправлений. Конфигурация развёртывания и workflow не менялась.

Штатный workflow обновляет сайт и обычный `Qorgau-Student.exe`. Автономный EXE и установщик собираются как артефакты Actions. Ссылка скачивания автономного EXE использует GitHub Release текущей версии: релизы и версии в рамках редизайна не изменяются. Версия 0.5.1 унаследована из актуального `main` вместе с исправлениями браузера и паролей.
